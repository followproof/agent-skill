# Influencer audience check by Followproof

Influencer audit and influencer vetting as an agent skill. `SKILL.md` teaches an agent to check audience
quality and engagement rate for Instagram, TikTok and YouTube creators with Followproof's MCP server
(`https://followproof.com/mcp`) or REST API (`https://followproof.com/v1`), and how to present the
results fairly. The same file is served at https://followproof.com/skill.md.

```sh
npx skills add followproof/agent-skill
```
